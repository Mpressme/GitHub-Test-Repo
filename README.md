# Tadaow Landing Page

This repository now contains a complete concept landing page implementation for **Tadaow**, an AI music creation platform.

## Run locally

Open `index.html` directly in your browser, or serve with a static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included files

- `index.html` — full semantic page structure and copy
- `styles.css` — dark-themed design system and responsive layout
- `script.js` — waitlist form validation and success/error feedback behavior
